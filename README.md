## 🚀 Featured Projects

### Open Career Agent / Rolevia

An AI-powered job-search command centre designed to discover opportunities, evaluate candidate-job fit, tailor application materials, track applications, and coordinate agent-driven workflows.

**Stack:** TypeScript, Node.js, Fastify, React, SQLite, Drizzle, Docker, AI APIs

---

### Permission Drift Bench

A research-oriented benchmark and sandbox for testing **permission drift in tool-using AI agents**.

It models identities, tools, permissions, revocation events, and audit logs to measure whether agents continue performing actions after access has been revoked.

**Focus:** AI agent security, reliability, authorization, evaluation, tool-use safety

---

### ResolveAI

A Dockerized multi-service AI SaaS platform with authentication, workspaces, analytics, AI workflows, and production-oriented backend infrastructure.

**Stack:** TypeScript, React, Node.js, PostgreSQL, Docker, OpenAI API
